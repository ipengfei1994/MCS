# 核心问题

长时 Cahn–Hilliard 动力学（尤其晚阶段粗化）需要很长的物理时间模拟，计算昂贵 (p.1)。神经算子（FNO）等 SciML 代理模型虽能离线训练、在线廉价推演 (p.2)，但存在关键难点：

1. **一步准确 ≠ 长时可靠**：在单步监督对上学习到的映射即使准确，递归反复应用时小误差会累积放大，导致 (a) 非耗散的自由能演化、(b) 超出标称相场范围 [−1,1] 的大幅值振荡（excursion）、(c) 粗化保真度退化 (p.1)。
2. **刚性 + 细网格**：四阶扩散算子导致刚性，显式格式稳定性要求 δt ≲ Ch⁴；隐式/能量稳定格式虽放宽限制仍需小步长以解析界面松弛，长时模拟步数巨大 (p.2)。
3. **现有 SciML 评测不充分**：许多研究用确定性初值、短区间、受控测试问题，未包含 CH 作为相分离模型的本质特征——晚阶段粗化、特征长度增长、结构函数标度塌缩 (p.3)。
4. **FNO 对时间采样敏感**：实验表明一步训练数据的时间采样分布不同，可导致 FNO 长时预测从有界变为大幅越界 (p.19–20)。

# 方法框架

核心思路：在 FNO 架构基础上，按"先稳定、后修正统计"的两阶段注入物理结构（文字框图）：

```
            Cahn–Hilliard 参考数据（粗时间步 ∆T=20）+ FNO 主干
                              │
        ┌─────────────────────┴─────────────────────┐
    Stage I: bcFNO（Bound-Conforming）         目标：压制幅值越界、稳定能量
        在状态损失上加软幅值惩罚 L_bc（softplus，β=5，
        不硬性投影，仅对超出 [−1,1] 的偏离做幅值相关惩罚）
                              │ （Stage II 从 Stage I 模型继续训练）
                              ▼
    Stage II: spFNO（Structure-Preserving）      目标：修正晚阶段粗化统计
        保留 L_bc，新增结构函数正则 ℓ_sk
        （谱形项 ℓ_shape + 峰值项 ℓ_peak + 低强度项 ℓ_null，
         仅对粗化区间样本、且从第 2 epoch 起激活）
                              │
                              ▼
            长时 rollout：在线推演成本与 FNO 相同（正则只改训练目标）
```

- FNO 主干：lifting 算子 P → 若干 Fourier 层（谱分支 R·低频频模 + 逐点分支 W 求和后过激活）→ projection 算子 Q (p.12–13)。Fourier 层更新式 (25) (p.13)。
- 两阶段目标分层：把"能量稳定性控制"与"晚阶段粗化统计修正"解耦 (p.4)。架构本身不变，故在线成本不增加 (p.26)。

# 技术细节与关键公式

### 1. Cahn–Hilliard 方程及其耗散/守恒律 (p.5)

自由能泛函（双井势 F(ϕ)=(ϕ²−1)²/4，κ>0 控制界面能）：

$$E[\phi]=\int_\Omega \Big(F(\phi)+\frac{\kappa}{2}|\nabla\phi|^2\Big)\,dr \tag{1}$$

化学势 μ = F′(ϕ) − κ∇²ϕ = ϕ³ − ϕ − κ∇²ϕ，H⁻¹ 梯度流给出经典 CH 方程：

$$\frac{\partial\phi}{\partial t}=M\nabla^2\big(\phi^3-\phi-\kappa\nabla^2\phi\big) \tag{2}$$

其满足**质量守恒**与**能量耗散律**：

$$\frac{dE}{dt}=-\int_\Omega M|\nabla\mu|^2\,dr\le 0 \tag{3}$$

> 含义：总自由能单调下降；这是长时行为可信的物理基线。CH 方程**无最大值原理**，故 |ϕ|≤1 只是"标称相场范围"而非普适不变式 (p.13)。

### 2. 晚阶段动态标度与 Lifshitz–Slyozov 增长律 (p.6–8)

结构函数 S(k,t) 在晚阶段粗化满足动态标度：

$$S(k,t)=L(t)^d\,F\big(kL(t)\big) \tag{5}$$

归一化结构函数 s(k,t)=S(k,t)/var(t)，其一阶谱矩给出特征波数 k₁(t)∝L(t)⁻¹，故 L(t)∝k₁(t)⁻¹ (p.7, 式10)。由 Gibbs–Thomson 关系 + Fick 定律推得扩散控制粗化的立方增长：

$$L^3(t)-L^3(t_0)\sim 3C(t-t_0)\quad\Rightarrow\quad L^3(t)\approx at+b \tag{15}$$

> 含义：L³(t) 在晚阶段近似对时间仿射，是与维度无关的基准粗化律，作为评估代理模型长时动力学的核心判据 (p.8)。

### 3. 边界保持惩罚 L_bc（Stage I）(p.13)

软逐点惩罚，对超出 [−1,1] 的偏离做幅值相关惩罚（不硬性投影）：

$$\mathcal L_{bc}=\frac{1}{N^2}\sum_{i,j}\Big[\operatorname{softplus}(\phi(x)-1;\beta)^2+\operatorname{softplus}(-1-\phi(x);\beta)^2\Big] \tag{26}$$

$$\operatorname{softplus}(z;\beta)=\frac{1}{\beta}\log(1+e^{\beta z}),\quad \beta=5 \tag{27}$$

### 4. 结构函数正则 ℓ_sk（Stage II）(p.14)

由三部分构成（B=64 径向波数箱，stopgrad 停止梯度）：

- 谱形项 ℓ_shape（峰值归一化后的均方差，式28）
- 峰值箱项 ℓ_peak（参考峰值 f·sᵣₑ_f^max 以上波数箱，式29）
- 低强度箱项 ℓ_null（参考峰值 τ_ρ·sᵣₑ_f^max 以下波数箱，式30）

单样本结构损失：ℓ_sk = w_shapeℓ_shape + w_peakℓ_peak + w_nullℓ_null (式31)。

整体小批量目标（状态损失 + 边界项对全体样本；结构项仅当 χ_c(t+∆T)=1，即粗化区间，且第 2 epoch 起）：

$$\ell_{state}=\frac{1}{N^2}\sum_{i,j}\big[\phi^{pred}_{t+\Delta T}-\phi^{ref}_{t+\Delta T}\big]^2 \tag{32}$$

$$L_{total}=\frac{1}{R}\sum_{r=1}^R\Big[\ell_{state}(t_r)+\lambda_{bc}\ell_{bc}(t_r)+\chi_c(t_r+\Delta T)\lambda_{sk}\ell_{sk}(t_r+\Delta T)\Big] \tag{33}$$

> 表1 汇总了 FNO / bcFNO / spFNO 各自激活的损失项 (p.14)。

# 实验结果

**设定**：2-D 周期域，M=1，κ=0.5，初值为零均值高斯噪声(σ=0.01)；参考解用一阶半隐式 Fourier 伪谱 (p.11)。粗监督间隔固定 ∆T=20，内部步长 δt∈{1,0.5,0.2,0.1}，分辨率 N∈{128,256}（8 个组合）(p.11–12, p.18)。每 (N,δt) 用 6 条训练轨迹 + 1 条独立 held-out 评估轨迹 (p.12)。

### 实验一：带解析解的强迫 CH（评测幅值惩罚）(p.17)
- 在 t=30000，相对场误差：FNO ≈ 4.9，bcFNO ≈ 0.28（FNO 出现大幅越界与形态畸变，bcFNO 抑制幅值增长但仍有空间位移）(p.17)。

### 实验二：无源 CH 粗化（评测完整框架）(p.18–24)
- **Table 4（代表案例，粗化区间拟合）**：(p.24)
  - (128,0.2)：L³ 斜率 a——参考 0.020 / bcFNO 0.0075 / spFNO 0.011；k₁ 指数 β——参考 −0.33 / bcFNO −0.13 / spFNO −0.16；塌缩分数 R_collapse——参考 1.00 / bcFNO 0.73 / spFNO 0.88。
  - (256,0.1)：a——0.020 / 0.0083 / 0.012；β——−0.28 / −0.12 / −0.16；R_collapse——1.00 / 0.91 / 0.91。
  - spFNO 的 a、β 均比 bcFNO 更接近参考；塌缩分数在 (128,0.2) 提升、(256,0.1) 持平。
- **结构函数修正**：bcFNO 与参考的最大差异集中在低波数粗化峰附近，spFNO 在该范围及邻近波数差异更小 (p.22–23, 图9–12)。
- **多训练种子**：Table B.9（256,0.1, Sampling B）——FNO 最大幅值 2.53~27.6，bcFNO 仅 1.15~1.23，说明 bcFNO 跨种子稳定压制越界 (p.34)。
- **在线成本**（Table 5，N=256，t∈[0,30000]）：谱求解器 δt=1 需 156s(CPU)、δt=0.1 需 1608s(CPU)；FNO/bcFNO/spFNO 均约 8.0s(GPU)，相对 FNO 时间比为 1.0 (p.26)。正则只改训练目标，不改变推演架构，故在线零额外成本。

# 贡献与对比

相对**标准 FNO**：
- 首次系统指出在粗时间步递归推演下 FNO 长时会能量增长、幅值越界、粗化统计失真；并给出"先幅值约束、后统计修正"的分层方案 (p.1, p.4)。
- bcFNO 在不增加在线成本前提下稳定长时预测；spFNO 进一步校正结构函数与 L³ 增长趋势 (p.26)。

相对**PINN**（物理信息神经网络）：
- 现有 PINN 工作主要提升 PDE 残差精度、场级误差、质量守恒与训练可训练性，多用短区间/受控问题 (p.2–3)。
- 本文走**算子学习**路线（一次训练、跨初值廉价推演），并用**统计标度**（结构函数、L³ 律、塌缩）而非仅场级误差评估长时保真度，直接针对 CH 相分离本质特征 (p.3, p.8)。
- 新颖点：把"标称相场可容许性"作为长时粗化统计有意义的**前提条件**，并以结构函数正则做针对性统计修正 (p.4, p.27)。

# 局限性与批判

**agree_with（认同）**
- 认同"一步准确 ≠ 长时可靠"这一核心观察，且用能量/幅值/统计三层指标量化，比单纯场误差更贴合 CH 物理；FNO 对时间采样敏感（图6）的实验证据扎实 (p.19–20)。
- 认同将 [−1,1] 明确定位为"标称参考范围"而非普适不变式（CH 无最大值原理），避免硬性投影带来的伪影，工程处理诚实 (p.13)。
- 认同"幅值控制是统计修正的前提"的层级论断，由 Eq.(35) 的 Parseval 上界与 Table 4 数据共同支撑，逻辑自洽 (p.21, p.27)。

**question（质疑）**
- 结构函数正则仅作用于**晚阶段粗化区间**且第 2 epoch 才激活，对早期失稳、结构形成等其他三阶段未覆盖；论文也承认"扩展到完整 CH 演化是重要方向"，故当前框架的长时可靠性在 early-stage 仍存疑 (p.27)。
- spFNO 的 L³ 斜率 a 仍明显低于参考（0.011 vs 0.020，约一半），说明粗化速率仍被系统性低估；"统计修正"是否真恢复物理速率、还是仅拟合谱形，需谨慎看待 (p.24)。
- 结构函数正则含多个经验超参（f_peak、τ_ρ、w_shape/w_peak/w_null 等），靠训练轨迹网格搜索选定，held-out 轨迹被排除但调参仍依赖同源数据分布；跨参数/跨维度泛化性未被检验（表 A.6 给范围但仅 2D 测试）(p.15, p.32)。

**complement（补充）**
- 可补充：将 bcFNO 的幅值约束与**质量守恒**联合监控（论文已监测空间均值但未作为硬约束），或引入能量耗散方向的软约束直接对应 Eq.(3)，可能比纯幅值惩罚更物理。
- 可补充：把结构函数正则推广到**早期/中期**阶段，或设计 stage-aware 多尺度算子，呼应论文未来工作 (p.27)；亦可考虑与 equivariant 多尺度神经算子 [36] 结合以提升细结构保真度。
- 可补充：在更高维（3D）与更粗 ∆T 下验证在线加速比与稳定性，因 2D 上 δt=1 已是该离散格式稳定极限 (p.11)。

# 历史影响与演进

- **1958/1961**：Cahn–Hilliard 方程与自旋分解理论奠基 [1,2]；**1961** Lifshitz–Slyozov 粗化动力学 L³∝t [51] —— 本文统计评测的物理根基。
- **2020**：Fourier Neural Operator（FNO）提出，胜任周期域上函数空间映射 [46]；同年起 PINN 用于 Allen–Cahn/CH 的系列工作涌现 [24–29] —— 本文方法基座。
- **2021–2025**：神经算子多样化（卷积/多小波/图/注意力算子）及 CH 专用算子学习（DeepONet+自编码 [34]、equivariant 多尺度 [36]）成熟 —— 本文定位"在算子学习中注入物理结构"这一细分方向。
- **本文（2025/2026）**：提出"结构保持 FNO + 粗时间步监督 + 两阶段（幅值界/结构函数）"，把动态标度（Furukawa 1985 [56]、Lifshitz–Slyozov）作为监督信号，开启"以统计标度约束长时算子学习"的设计范式，并展望湍流等具自相似统计的系统可复用此原则 (p.4, p.27)。
